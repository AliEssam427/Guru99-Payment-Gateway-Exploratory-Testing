# Guru99 Payment Gateway - Exploratory Testing Project

## Project Overview

This project demonstrates an Exploratory Testing approach performed on the **Guru99 Payment Gateway demo application**.

The project focuses on discovering functional, usability, validation, and unexpected behavior through structured exploratory testing sessions.

Unlike scripted testing, exploratory testing combines test design, execution, observation, and learning during the testing process.

---

## Project Objectives

- Explore the Payment Gateway application and its main workflows.
- Identify functional and usability issues.
- Discover unexpected application behavior.
- Validate important user scenarios.
- Document discovered defects with clear reproduction information.
- Maintain exploratory test documentation.
- Improve test coverage through session-based exploration.

---

## Testing Approach

The project follows an exploratory testing approach where test scenarios are created and executed while learning about the application.

The testing process includes:

1. Application exploration
2. Feature identification
3. Test idea generation
4. Test execution
5. Observation of application behavior
6. Defect identification
7. Defect documentation
8. Retesting and validation where applicable

---

## Exploratory Test Cases

The `Exploratory Test Case.xlsx` file contains the exploratory testing scenarios and test ideas used during the testing sessions.

The test cases focus on discovering defects through different user behaviors and input combinations rather than relying only on predefined scripted scenarios.

---

## Bug Report

The `Bug Report.xlsx` file contains defects identified during exploratory testing.

Each defect is documented with relevant information such as:

- Bug ID
- Bug Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Test Evidence
